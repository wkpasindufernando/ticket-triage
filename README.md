# Ticket Triage

A full-stack support-ticket triage app built with Angular, Spring Boot,
PostgreSQL, and a Python machine-learning service.

## Project structure

- `frontend/` — Angular application
- `backend/` — Spring Boot REST API
- `ml-service/` — Python model API and training code
- `infra/` — Docker and deployment configuration
- `docs/` — architecture and project documentation
